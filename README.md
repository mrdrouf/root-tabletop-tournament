# Root: Tournament Edition -- art

The images, models and sounds the Root: Tournament Edition save for Tabletop Simulator loads, served by
GitHub Pages at `https://mrdrouf.github.io/root-tabletop-tournament/art/<SHA-1>`.

Each file is named by the SHA-1 of its bytes. For art that first lived on Steam Cloud that is the hash at
the end of its old Steam link; `index.json` lists every file with the link or links it replaces.
Files are only ever added here, never changed or removed: saves made with any version keep loading.

Most of this art was made by Leder Games, or by the Root community for the Root - Ultimate Collection
Workshop mod, and belongs to its makers. It is kept here so the mod's tables can keep loading it.
